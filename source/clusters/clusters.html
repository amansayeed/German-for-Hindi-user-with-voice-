📚 Quick Reference Guide

🔴 Most Important:
SCH = श (always!)
CH = ह्य/ख (depends on vowel)
ST = श्ट (at start only)
SP = श्प (at start only)
⚠️ Common Mistakes:
TH ≠ English "th" (it's "त")
KN: K is NOT silent!
QU = क्व (not क्यू)
PF = प्फ़ (both sounds!)
💡 Easy Ones:
BL = ब्ल (like "blue")
BR = ब्र (like "brother")
FL = फ्ल (like "fly")
FR = फ्र (like "friend")

🔊 Pronunciation Rule:
- 'B' is pronounced as in English 'b', 'L' as in English 'l'.
- Soft blend, both letters clearly heard.
- Tip: Think "BL" as in "BLue" or "BLood" - same sound!
💡 Memory Tip: BL = "ब्ल" - Just like saying "blue" but with German words! Remember: Blut (blood) = ब्लूट - both start with BL!

CH - The Tricky One! 🎯

🔊 Pronunciation Rule:
- After front vowels (e, i, ä, ö, ü) → soft [ç] (like ह in "ह्य") e.g., ich.
- After back vowels (a, o, u) → hard [χ] (guttural, like Scottish 'loch').
- Tip: Front vowels = soft "ह्य" sound, Back vowels = throaty "ख" sound!
💡 Memory Tip: CH has TWO sounds! Front vowels (e, i) = soft like "ich" (इख). Back vowels (a, o, u) = hard like "Buch" (बुख). Remember: "ich" is soft, "Buch" is hard!

1Chemie🔊केमीChemistryरसायन विज्ञान
2Licht🔊लिख्टLightरोशनी
3Buch🔊बुखBookकिताब

ST - Changes Position! 🔄

🔊 Pronunciation Rule:
- Initial 'ST' pronounced [ʃt] (श्ट), middle of word as English 'st'.
- Tip: At START = "श्ट", in MIDDLE = normal "st"!
💡 Memory Tip: ST at the BEGINNING = "श्ट" (like Stadt = श्टाट). ST in the MIDDLE = normal "st" (like beste = बेस्टे). Position matters!

TH - Just "T" Sound! 🎯

🔊 Pronunciation Rule:
- German 'TH' is always pronounced as [t] (like English 't'), never as English 'th'.
- Tip: TH = "त" or "थ" - NEVER English "th" sound!
💡 Memory Tip: German TH = "T" sound only! Theater = थिएटर (not "thee-ater" like English). Think "T" not "TH"!

KN - K is NOT Silent! ⚠️

🔊 Pronunciation Rule:
- Both 'K' and 'N' are pronounced (क्न), unlike English where 'K' is silent.
- Tip: Say "क" + "न" - K is NOT silent like in English!
💡 Memory Tip: In English "knee" = "nee" (K silent). In German "Knie" = "क्नी" (K is pronounced!). Always say the K!
