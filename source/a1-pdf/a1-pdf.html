Wortliste - Vocabulary List

📖 About This List

This vocabulary list contains approximately 650 words for the Goethe-Zertifikat A1 Start Deutsch 1 examination. The A1 level represents elementary language use according to the Common European Framework of Reference for Languages (CEFR).

Key Points:

  • All words should be understood passively when encountered in spoken or written texts
  • About half of these words (~325) should be available as active vocabulary
  • Words are organized by themes and word groups
  • Example sentences illustrate word usage
  • Female forms (e.g., Lehrerin) are part of the required vocabulary alongside masculine forms
